# Community and Pro

Community is the public first-pass scanner. It stays focused on checks that are useful, transparent, and easy to verify with native ROS 2 tools.

Pro is planned for deeper debugging workflows where the useful part is correlation across multiple subsystems rather than a single observation.

| Capability | Community | Pro |
| --- | :---: | :---: |
| Environment and graph checks | ✓ | ✓ |
| Expected node/topic checks | ✓ | ✓ |
| Basic TF availability | ✓ | ✓ |
| Topic-rate sampling | ✓ | ✓ |
| Text / JSON output | ✓ | ✓ |
| QoS reasoning | — | ✓ |
| TF history | — | ✓ |
| Odometry anomaly analysis | — | ✓ |
| Localization correlation | — | ✓ |
| Nav2 dependency diagnosis | — | ✓ |
| rosbag / incident analysis | — | ✓ |
| HTML reports | — | ✓ |
| CI readiness profiles | — | ✓ |

Pro is not required to contribute to or use the Community edition.
