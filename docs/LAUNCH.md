# Launch checklist

Before public promotion:
- CI green on Python 3.10-3.12
- Run the built-in demo on a clean machine
- Validate at least three Gazebo/Nav2 failures
- Add one terminal GIF to the README
- Publish a versioned GitHub release
- Keep all employer/customer maps, bags, configs, credentials, and robot-specific IP out of the public repo
- Ask external ROS users to reproduce the demo before making performance claims

Positioning: **"Capture the evidence around a ROS 2 runtime failure before it disappears."**
